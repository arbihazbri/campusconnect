# CampusConnect

Plateforme d'entraide entre étudiants : demandes d'aide, propositions, suivi des séances et évaluations.

Projet universitaire, sujet « CampusConnect » (React / Next.js).

## Stack technique

- Frontend : Next.js, React, TypeScript
- Backend : Java, Spring Boot
- Base de données : PostgreSQL
- Versionnement : Git et GitHub
